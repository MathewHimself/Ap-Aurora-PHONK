# АП Aurora PHONK

Веб-сэмплер в стиле дрифт-фонка: пэды ковбелла, 808 и ударных, педали эффектов на каждую группу звуков, 16-шаговый секвенсор, микшер с отдельным каналом для каждой группы и визуал «аврора», который реагирует на громкость. Все звуки синтезируются в браузере через [Tone.js](https://tonejs.github.io/), аудиофайлы не нужны.

Это минимальный рабочий прототип без сборки. Файлы разложены по структуре «Code beginning»:

```
index.html            только разметка
Stylesheets/
  style.css           точка входа: только @import
  reset.css           обнуление стилей (Eric Meyer reset v2.0)
  fonts.css           @font-face для Onest из /fonts
  layout.css          переменные, базовые стили и все компоненты
  animation.css       transition и prefers-reduced-motion
  adaptive.css        медиазапросы
Javascripts/
  scripts.js          звук (Tone.js) и вся логика интерфейса
fonts/                Onest (woff2, лицензия OFL)
images/               картинки и иконки (favicon.svg, иконки ▶ и ⏸, иконки вкладок)
```

## Как запустить

Открой `index.html` в браузере и нажми «Включить звук». Браузеры разрешают звук только после действия пользователя, поэтому без этой кнопки ничего не заиграет.

Если браузер блокирует открытие файла напрямую, подними локальный сервер в папке проекта:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Управление

| Группа | Пэды | Клавиши |
|---|---|---|
| Ковбелл (минорная пентатоника) | 1, b3, 4, 5, b7, 8 | A S D F G H |
| Ударные | Kick, Clap, хэт, открытый хэт, ролл, Impact | Q W E R T Y |
| 808 | тоника, квинта, октава, глайд | Z X C V |

В углах экрана регулируются темп (от него зависит скорость хэт-ролла) и громкость. Кнопка ▶ под логотипом запускает луп из секвенсора, ⏸ ставит его на паузу; поверх лупа можно играть пэдами. Стрелки рядом меняют тональность: ковбелл и 808 перестраиваются вместе.

Под шапкой два экрана: **01 Аврора** (пэды, педали, микшер) и **02 Секвенсор**. Переключаются кликом или стрелками ← →. В секвенсоре сетка 16 шагов на каждую строку пэдов: клик по клетке ставит или убирает ноту, изменения слышны сразу, даже во время игры. По умолчанию загружен дрифт-фонк паттерн A. Кнопки M и S у групп — те же, что в микшере.

Под пэдами стоит микшер: полосы КОВБЕЛЛ, УДАРНЫЕ, 808 и МАСТЕР. У каждой группы есть фейдер громкости (−∞…+6 дБ), панорама, кнопки M (mute) и S (solo) и индикатор уровня. Двойной клик сбрасывает фейдер в 0 дБ, а панораму в центр. Клавиши 1, 2 и 3 глушат ковбелл, ударные и 808. Фейдер мастера и угловая ручка громкости двигаются вместе.

## Как устроен звук

- **Ковбелл** — два прямоугольных осциллятора в соотношении частот 1 : 1,48 через полосовой фильтр с короткой огибающей, как у TR-808. Шина: дисторшн → ревёрб.
- **808** — синусоида с коротким падением высоты в атаке (`MembraneSynth`). Глайд стартует октавой выше и съезжает к тонике. Шина: дисторшн → фильтр.
- **Ударные** — бочка на `MembraneSynth`, клэп из трёх быстрых шумовых ударов через полосовой фильтр, хэты на шуме через ВЧ-фильтр (закрытый хэт глушит открытый). Шина: биткрашер → ревёрб.
- **Каналы** — каждая шина заканчивается своим каналом (`Tone.Channel`: громкость, панорама, mute, solo) с индикатором уровня, и только потом звук попадает на мастер. Impact со своим длинным ревёрбом идёт через канал ударных.
- **Мастер** — компрессор → лимитер → потолок → громкость.

Маршрутизация:

```
ковбелл → дисторшн → ревёрб → КАНАЛ КОВБЕЛЛ ┐
808 → дисторшн → фильтр → КАНАЛ 808         ├→ компрессор → лимитер → МАСТЕР
ударные → биткрашер → ревёрб → КАНАЛ УДАРНЫХ ┘
```

Каждую педаль можно выключить тумблером в её заголовке.
