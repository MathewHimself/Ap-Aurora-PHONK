# АП Aurora PHONK

Веб-сэмплер в стиле дрифт-фонка: пэды ковбелла, 808 и ударных, педали эффектов на каждую группу звуков и визуал «аврора», который реагирует на громкость. Все звуки синтезируются в браузере через [Tone.js](https://tonejs.github.io/), аудиофайлы не нужны.

Это минимальный рабочий прототип без сборки. Файлы разложены по структуре «Code beginning»:

```
index.html            только разметка
Stylesheets/
  style.css           точка входа: только @import
  reset.css           обнуление стилей (Eric Meyer reset v2.0)
  fonts.css           @font-face для Onest из /fonts
  layout.css          переменные, базовые стили и все компоненты
  animation.css       transition и prefers-reduced-motion
  adaptive.css        медиазапросы
Javascripts/
  scripts.js          звук (Tone.js) и вся логика интерфейса
fonts/                Onest (woff2, лицензия OFL)
images/               картинки и иконки
```

## Как запустить

Открой `index.html` в браузере и нажми «Включить звук». Браузеры разрешают звук только после действия пользователя, поэтому без этой кнопки ничего не заиграет.

Если браузер блокирует открытие файла напрямую, подними локальный сервер в папке проекта:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Управление

| Группа | Пэды | Клавиши |
|---|---|---|
| Ковбелл (минорная пентатоника) | 1, b3, 4, 5, b7, 8 | A S D F G H |
| Ударные | Kick, Clap, хэт, открытый хэт, ролл, Impact | Q W E R T Y |
| 808 | тоника, квинта, октава, глайд | Z X C V |

В углах экрана регулируются темп (от него зависит скорость хэт-ролла) и громкость. Стрелки под логотипом меняют тональность: ковбелл и 808 перестраиваются вместе.

## Как устроен звук

- **Ковбелл** — два прямоугольных осциллятора в соотношении частот 1 : 1,48 через полосовой фильтр с короткой огибающей, как у TR-808. Шина: дисторшн → ревёрб.
- **808** — синусоида с коротким падением высоты в атаке (`MembraneSynth`). Глайд стартует октавой выше и съезжает к тонике. Шина: дисторшн → фильтр.
- **Ударные** — бочка на `MembraneSynth`, клэп из трёх быстрых шумовых ударов через полосовой фильтр, хэты на шуме через ВЧ-фильтр (закрытый хэт глушит открытый). Шина: биткрашер → ревёрб.
- **Мастер** — компрессор → лимитер → громкость.

Каждую педаль можно выключить тумблером в её заголовке.
